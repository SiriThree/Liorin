## Source Baseline Failures To Account For

The source repository cannot be imported blindly:

- `tests/test_evidence_verifier_stage3.py` uses `Document(text, md)`, but current LangChain expects keyword construction such as `Document(page_content=text, metadata=md)`.
- `test_trace_and_feedback_do_not_store_raw_pii` reads UTF-8 JSONL using platform default encoding on Windows.

Migration tests must be adapted to current dependency behavior instead of copying failing assumptions.
