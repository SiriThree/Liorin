# Annotation Guide

## 基本原则

- 只标注输入与冻结来源能够支持的事实。
- 手册与政策优先于 FAQ；数据库当前状态优先于历史工单旧状态。
- 历史工单 `resolved` 只说明状态，不等于已知具体解决方案。
- 缺少产品、型号、身份或必要业务字段时，Gold 应为澄清、验证或受限回答，而不是猜测。

## Retrieval qrels

- 3：直接且完整回答核心需求。
- 2：回答核心需求的重要组成部分。
- 1：背景相关，但单独不足以回答。
- 0：不相关或 Hard Negative。

## 原子事实

每条事实必须：

1. 只有一个主要主张；
2. 带 `source_refs`；
3. 数字、否定、条件和主体与来源一致；
4. 不把推荐步骤写成历史上已经执行的动作。
