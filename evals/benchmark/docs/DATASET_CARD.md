# Dataset Card

## 目的

评测客服 Agentic RAG 的查询理解、知识源路由、全语料检索、证据生成、闭环行为和端到端决策能力。

## 来源与权威等级

1. 产品手册、售后政策：冻结权威源，不修改事实。
2. 订单、工单、质保数据库：结构化当前状态。
3. FAQ：由手册/政策派生，每条保留来源引用。
4. 历史工单：只使用数据库可验证的症状、状态和事件；未记录的实际解决步骤明确视为未知。

## 切分

- 产品：Dev 为 001–012，Validation 为 013–016，Blind Test 为 017–020。
- 政策章节、数据库实体和表面模板同步隔离。
- 公开包只包含盲测输入；维护者包单独保存 Gold。

## 局限

- 尚无独立双人标注与一致性系数。
- 语料是单一企业模拟域，不能外推至所有客服场景。
- 自由文本事实覆盖的确定性得分只是代理指标；正式生成质量需按锁定 Judge 或人工协议复核。
- 拿到私有 Gold 后再次调参会破坏盲测有效性。
